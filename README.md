# BMI Calculator — Flutter

## Overview
A Flutter BMI calculator that collects gender, height, weight, and age, calculates Body Mass Index, and displays the result on a dedicated result screen.

## Features
- Male / female selection.
- Adjustable height.
- Weight and age controls.
- BMI calculation from the entered measurements.
- Separate result screen showing gender, age, and calculated BMI.
- Responsive Flutter layout built with Material widgets.

## Project Structure
```text
lib/
├── main.dart
├── home.dart
└── result.dart
```

## Tech Stack
- Flutter
- Dart
- Material Design

## Run
```bash
flutter pub get
flutter run
```

## Purpose
This project demonstrates Flutter state management with `StatefulWidget`, navigation between screens, interactive controls, and basic calculation logic.
